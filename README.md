> This project is deprecated and no longer maintained.
> For CLI parsing, [Commander](https://www.npmjs.com/package/commander) now has really good TypeScript typings.
> Node.js now [supports running TypeScript code out of the box](https://nodejs.org/docs/latest/api/typescript.html),
> and may come with a [built-in logger](https://github.com/nodejs/node/pull/60468) at some point.

# tkt

`tkt`, pronounced **toolkit**, is an opinionated toolkit for building Node.js applications. Comes with good IntelliSense support thanks to TypeScript.
